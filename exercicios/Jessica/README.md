# Copie esta pasta

1. Copie a pasta `SEU-NOME` inteira.
2. Renomeie a cópia com o seu primeiro nome, minúsculo e sem acento: `ana`,
   `bruno`, `carla`.
3. Quando os três já tiverem a sua, apague a `SEU-NOME`.

Dentro dela, o `aula02.sql` já vem com os marcadores no lugar. Você escreve
embaixo de cada um. Os arquivos das aulas seguintes você cria do mesmo jeito,
com o mesmo padrão de nome.
